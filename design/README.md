# Tula design

The active `v3.x_spack` Tula design is:

- [`COMPONENTS.md`](COMPONENTS.md): public components, dependency adapters,
  minimal dependency closure, and acceptance rules.

System-wide architecture, workflow, test evidence, and the technical HTML deck
are maintained in `tula_cmake/design/`, because they describe the complete
Spack/TulaCMake/Tula lifecycle rather than Tula source alone.

Superseded Conan 2 documents are retained under [`archive/conan2/`](archive/conan2/)
as historical evidence. They are not build inputs or current guidance.
